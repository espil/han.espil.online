Plushy AI - free, local AI asset generation for game developers

Your GPU makes your game assets. No cloud, no per-generation fees, nothing uploaded.

Plushy AI is a free, open-source tool (MIT) that turns text prompts into transparent game sprites and single images into textured 3D models, entirely on your own machine. It is the tool we built to produce assets for our own games, released so other developers can use it too.

Mode 1 - Text to sprite

Type a prompt, get a transparent PNG sprite.

  • SDXL-Turbo generation with automatic background removal (rembg)
  • About 5 seconds per sprite on an RTX 4060
  • Transparent background, ready to drop into a 2D game
  • Set the seed to reproduce a result, and the size from 64 to 1024 px

Prompt in, game sprite out - no subscription counter ticking while you iterate.

Mode 2 - Image to 3D model

Give it one image, get a textured 3D model in GLB format.

  • Stable Fast 3D reconstruction from a single image (a plain white background works best)
  • Decimated to a game triangle budget: 8,000 triangles by default, 20,000 for landmark models
  • Textures at 1024-2048
  • Ships meshopt-compressed, plus an uncompressed twin for loaders without meshopt support (for example Unity glTFast)
  • A JSON spec sidecar is written next to every model

Cloud image-to-3D tools hand you whatever mesh they feel like. Plushy AI hands you a model sized for a game engine.

Mode 3 - Batch production

Point it at a folder of images and a JSON manifest, and convert the whole set unattended.

  • Every asset produces a compressed GLB, an uncompressed GLB, and a spec sidecar
  • Re-running skips finished assets, so a batch can be stopped and resumed at any point
  • Ready-made launcher scripts are included
  • This is the mode we use for production runs on our own games

Plushy AI Studio - one page does everything

Plushy AI runs as a local web app. The Studio page gives you:

  • A prompt box with live job progress
  • Sprite and image-to-3D modes in one place
  • An in-browser 3D preview of generated models
  • A gallery of your output folder with downloads
  • Job history and cancel

Open it at http://localhost:8000/studio once the container is up. On Windows, the included start-gui.bat also serves the Studio to other devices on your LAN.

Requirements

  • An NVIDIA GPU with 8 GB VRAM or more
  • Docker Desktop, or Docker Engine with the NVIDIA container toolkit
  • A Hugging Face token, needed once on the first run to download the gated SDXL-Turbo model
  • About 18 GB of downloads on the first run (all model weights, downloaded visibly, cached in a Docker volume, then used offline)

FAQ

Is Plushy AI really free? Yes. Plushy AI is open source under the MIT license, free for personal and commercial use. There are no per-generation fees and no subscription, because generation happens on your own GPU instead of a cloud service.

Does Plushy AI upload my images or prompts anywhere? No. Generation runs locally in a Docker container on your machine and outputs stay in your own output folder. Model weights are downloaded once on the first run and cached; after that the tool works offline.

What GPU do I need for Plushy AI? An NVIDIA GPU with 8 GB of VRAM or more, plus Docker. As a reference point from our own testing in the README: a sprite takes about 5 seconds on an RTX 4060, and a 3D conversion takes roughly 4 minutes per model on the same card.

What formats does Plushy AI output? Sprites are transparent PNG files. 3D models are GLB files - meshopt-compressed by default, with an uncompressed twin for loaders without meshopt support - plus a JSON spec sidecar for each model. Models are decimated to game triangle budgets: 8,000 triangles by default, 20,000 for landmarks.

Can I use Plushy AI assets in a commercial game? Yes. The tool is MIT-licensed for personal and commercial use, and it exists to make assets for real games - we use it for our own. As with any AI tool, you are responsible for checking that your inputs and use comply with the licenses of the underlying models and your own obligations.
