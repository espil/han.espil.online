Ryde × TransLink

Ryde is an all-in-one transit app I built with a team at BCIT — it integrated the TransLink API wholesale: real routes, real data, end to end. The SkyTrain stop database below is the project's own data file, running live on this page: every station on the Expo and Canada Lines, in running order, with its TransLink stop ID.

Team repository: github.com/irvinalcira/ryde — the database is skytraindb/Stops.json from that repo.

    80 stop records across two lines and five directions. The same database drove the app's SkyTrain screens (SkyTrainRoute in the repo); here it drives this page, unchanged.
